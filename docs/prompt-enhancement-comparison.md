# 提示词增强对照结果

实测日期为 2026 年 11 月 25 日。两组各使用相同的 24 条合成草稿，服务端模型标识均为 `glm-5.3-flash`。旧版使用未经改动的 ByteRax `v1.5.23` 系统指令，新版只替换改写指令并在原生回填前检查关键原文。两组沿用同一供应商、请求协议、输出上限和响应解析。每对交替首发版本，并发为 4。

其余 8 组盲评持平。两名 AI 评审各查看一部分打乱顺序的配对输出，按原草稿的动作、约束、产物和清晰度评审。每个样本由一位评审判断。没有运行改写后的编程任务，结果衡量草稿本身。

一条含多项约束的长草稿首轮新版未通过供应商完成状态校验，客户端保留当前草稿。用同一模型和草稿复跑时，两版均返回正常结束状态 `stop`。本次复跑单独记录，首轮成功率和盲评仍按原始批次计算。

## 典型差异

- 旧版在正则和 PowerShell 路径中各发生一次反斜杠重复。新版保留了两处字面量和带参数的原始命令。用同一套校验核对两组返回文本。
- 原稿要求按给出的命令跑测试，并且只输出失败用例名与断言差异。旧版额外要求全绿时也报告。新版保留限定的交付内容和命令。
- 在纯 SQL 原因解释的样本里，旧版额外要求查询修改方案和修改后的 SQL。新版保留解释请求、时区要求和原 SQL 块。
- 旧版在受众描述和计时差异排查两个样本上获得更高偏好，差异涉及受众措辞与调查交付的具体程度。
